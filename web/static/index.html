Label Designer

Batch

    . Drag to move, corners to resize (snaps to 0.5 mm, hold Alt for 1 dot). Arrows nudge, Shift+arrows by 1 dot, Delete removes, Ctrl+D duplicates, R / Shift+R turns text, Ctrl+Z / Ctrl+Shift+Z undo and redo.

    Variables

    First line names the columns (comma or tab separated); each line after it prints one label. Click a name to put it in the selected text or QR data. {n} counts printed labels from Start, {n:03} pads it to 3 digits.
